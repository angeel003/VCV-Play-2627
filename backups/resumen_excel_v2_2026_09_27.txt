Fecha de respaldo: 27/09/2026

Para que esta versión de la web (HTML y JS) funcione correctamente, la base de datos de Google Sheets debe tener la siguiente estructura y configuración:

1. Pestaña "Ajustes":
   - Las abreviaturas personalizadas (2-3 letras) para los equipos se configuran en las columnas L (Columna 12) y M (Columna 13).
   - Estas abreviaturas se utilizan automáticamente en la web si no hay un logo disponible.

2. Pestaña "Partidos":
   - Columna J (Columna 10): Se utiliza para colocar los enlaces de streaming (YouTube, Twitch, etc.) de cada partido.
   - La Intranet de Administrador permite subir estos enlaces directamente a esta columna.
   - Los partidos se mantendrán visibles en el panel de administrador y para enviar pronósticos hasta 48 horas después de su hora de comienzo (para dar margen a subir resultados o ver el diferido).

3. Sistema de Puntuación (Ranking):
   - La web utiliza el "Standard Competition Ranking" (ej: 1, 1, 3). Los usuarios con los mismos puntos obtendrán exactamente el mismo puesto numérico, y el siguiente saltará tantos puestos como empatados haya.
   - Las flechas de tendencia (sube, baja, se mantiene) se calculan automáticamente en el frontend comparando el histórico de puntos, usando `maxJornadaJugada` para evitar saltos prematuros.

4. Despliegue:
   - El código en `Codigo_v2_funciona_27/09/2026.js` debe estar desplegado como Aplicación Web (Google Apps Script) configurado para que "Cualquier persona" tenga acceso.
   - La URL generada por Apps Script debe estar correctamente enlazada en la variable `scriptURL` del `html_v2_funciona_27/09/2026.html`.
